# 🎮 Simon Says Game

An interactive memory-based game built using HTML, CSS, JavaScript, and Bootstrap. The game challenges players to remember and repeat an increasingly long sequence of colours.

## 🚀 Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap

## ✨ Features
- Interactive colour buttons
- Random sequence generation
- Increasing difficulty levels
- User input and sequence validation
- Level-based gameplay
- Game-over functionality

## 📚 What I Learned
- JavaScript DOM manipulation.
- Event handling using JavaScript.
- Working with arrays and random sequences.
- Implementing game logic.
- Managing user interactions and game levels.
- Using Bootstrap for styling and layout.
- Improving frontend development skills.

This project helped me strengthen my JavaScript fundamentals by building an interactive browser-based game. It improved my understanding of programming logic, DOM manipulation, event handling, and frontend styling.
